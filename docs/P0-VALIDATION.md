# P0 修改与验证记录

日期：2026-11-04。修改前基线为 `0146a2a`，修改后为本次工作区中的 P0 实现。环境：macOS arm64、Node 26.8.1、独立 Chrome 156、1280 × 720 视口。没有读取用户账号或调用真实模型。

## 改了什么

- 认证状态：同一认证文件的同进程操作排队，重叠的只读请求共享一次文件读取；潜在写入入队即使共享读失效。完成的快照不留作 TTL 缓存。跨进程文件锁、文件权限检查、token 轮换原子保存和账号切换检查保留。
- 发送前一致性：统一 settings 与公开身份的快照，使 provider 使用最后一次验证的配置。试验过移除第二次预检查，但跨进程竞态测试证明会扩大旧配置发送窗口，因此最终保留两次发送前校验与一次完成校验。**单批 Host 的 settings/auth 调用仍各为 3 次；减少的是重叠查询的实际读锁和读取工作，不是删除这些串行保护。**
- 正文提取：接纳 SECTION、ARTICLE、FIGCAPTION、自定义块和块级 SPAN 的正文；短标题需要语义、正文上下文或标题样式信号；无有效候选的 main 依次回退 article、body。链接菜单、透明内容、代码独占块与编辑区仍过滤。隐藏装饰锚点不影响有效标题。
- 动态显示：CSS 动画/可见性过渡结束后重新发现正文，避免起初透明、淡入时无 DOM mutation 的正文永久漏选。流式写入、取消和源范围失效检查保留。
- 基线：新增独立浏览器/状态基准、诊断汇总器以及时钟身份、日志截断和首次完成记录。缺失、失败、取消不计作成功的 0 ms。

## 当前页面基线

真实 PageTranslator + TranslationReuse + IndexedDB，翻译服务为首个片段12ms、完成25ms的模拟实现。固定12段页面，每种条件5轮；以下为p50。首段指可见DOM文本，不是浏览器paint。

| 条件 | 首段 | 固定首屏 | 初次整页完成 |
|---|---:|---:|---:|
| 缓存未命中 | 21.0 ms | 63.3 ms | 266.2 ms |
| 缓存命中 | 5.5 ms | 5.3 ms | 13.6 ms |

滚动到新区域的未命中样本：首个新译文p50 28.7ms、固定新屏完成p50 71.1ms。缓存命中后再滚动，已完成的译文可立即使用；新译文事件缺失仍为unknown，不把它写成0ms模型生成。

这些是为后续回归建立的模拟服务基线，不是与旧版本或沉浸式翻译的真实服务对跑。5轮不足以承诺稳定的尾延迟。连接条件标为unknown，没有把第二轮称为热TLS连接。完整分布与逐轮数据保留在 `test-results/performance-browser.json`。
